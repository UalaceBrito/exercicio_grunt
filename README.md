# Exercício Grunt

Projeto profissional para demonstrar automação com Grunt, compilação de LESS e minificação de JavaScript.

## Estrutura do projeto

- `src/less/estilo.less` — arquivo principal de estilos em LESS
- `src/js/script.js` — JavaScript de exemplo com interatividade
- `dist/css/estilo.css` — arquivo CSS gerado pela compilação do LESS
- `dist/js/script.min.js` — arquivo JavaScript minificado
- `index.html` — página de exemplo da aplicação
- `Gruntfile.js` — configuração das tarefas do Grunt

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Rode o Grunt:
   ```bash
   npx grunt
   ```

3. Abra o arquivo `index.html` no navegador para visualizar a página.

## Tecnologias utilizadas

- Node.js
- npm
- Grunt
- LESS
- JavaScript

## Objetivo

Automatizar a geração de arquivos de produção, mantendo o projeto organizado e prático para execução e avaliação.
