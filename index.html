Recursos

Tudo que o seu front-end precisa, em um único pipeline

Cada etapa do build foi pensada para entregar o menor arquivo possível, sem sacrificar a experiência de desenvolvimento.

Compilação LESS

Variáveis, mixins e aninhamento transformados em CSS limpo, com sourcemaps para depuração em tempo real.

Compressão JS

UglifyJS reduz o tamanho dos scripts removendo espaços, renomeando variáveis e eliminando código morto.

Otimização CSS

Minificação agressiva com preservação de comportamento, gerando arquivos até 70% menores que o original.

Lint integrado

ESLint roda a cada alteração, garantindo consistência de estilo e evitando erros antes do commit.

LiveReload

Servidor local com recarregamento automático a cada alteração em LESS, JS ou HTML. Zero fricção.

Build reprodutível

Lockfile versionado e versões travadas garantem que o resultado seja idêntico em qualquer máquina.

Processo

Do código-fonte ao artefato final em um comando

O pipeline foi desenhado para ser previsível: cada etapa tem uma responsabilidade clara e pode ser executada isoladamente durante o desenvolvimento.

  1. 01

    Limpeza

    Remove artefatos antigos para evitar builds inconsistentes.

  2. 02

    Validação

    ESLint bloqueia o build se houver erros de estilo ou lógica.

  3. 03

    Compilação

    LESS gera CSS legível (dev) e minificado (prod).

  4. 04

    Otimização

    UglifyJS, cssmin e htmlmin entregam o menor bundle possível.
